# Pregunta
Paciente con PA no controlada pese a tres fármacos a dosis óptimas (incluido un diurético). ¿Qué fármaco se recomienda agregar como cuarta línea en HTA resistente?

## Opciones
- (x) Espironolactona
- ( ) Un segundo IECA
- ( ) Hidralazina
- ( ) Furosemida en bolo

## Justificación
En HTA resistente, al esquema de IECA/ARA-II + bloqueador de calcio + tiazida se agrega espironolactona como cuarto fármaco, salvo contraindicación (hiperkalemia, ERC avanzada).

# Pregunta
¿Cuál es una característica distintiva del carvedilol frente a otros betabloqueadores?

## Opciones
- (x) Tiene actividad bloqueadora alfa-1 adicional (vasodilatadora)
- ( ) Es cardioselectivo beta-1 puro
- ( ) Solo actúa sobre receptores beta-2
- ( ) Carece de efecto sobre la frecuencia cardíaca

## Explicación
El carvedilol es un betabloqueador no selectivo con bloqueo alfa-1 adicional, lo que le da efecto vasodilatador. Es uno de los betabloqueadores que reduce mortalidad en insuficiencia cardíaca con FE reducida.

## Etapa: manejo
Ecocardiograma confirma estenosis aórtica severa sintomática. ¿Conducta?
### Opciones
- (x) Derivar a reemplazo valvular (quirúrgico o TAVI)
- ( ) Manejo solo con diuréticos de forma indefinida

## Resumen
